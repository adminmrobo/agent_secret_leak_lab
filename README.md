# 확률로 읽는 보안 사건 — 승인 기록 유출

AI 코딩 비서의 승인 기록 파일(`.claude/settings.local.json`)에서 비밀값이 나온 사건(Apiiro 조사, 2026-11)을 연구실 식구들이 풀어 보는 해설 시리즈입니다.

| 편 | 페이지 | 내용 |
|---|---|---|
| 01 | [승인 한 번이 유출이 되기까지](01_settings_leak_probability.html) | 조건부확률 → 베이지안 갱신 → 마르코프 연쇄 → 역진적 귀납법 네 칸으로 사건 읽기 |
| 02 | [토론의 밤 — 비밀번호가 새어 나간 사건, 누가 막아야 할까](02_debate_settings_leak.html) | 인턴 브리핑과 용어 노트, 도구 책임 vs 사용자 책임 토론, 토론 전후 투표로 표 이동과 우도비 읽기 |

- 출연: 박사 · 조수(하루) · 초파리 연구원 · 주판봇 · 인턴 시아 · 인턴 모아 · 미공개 식구 3
- 페이지는 각각 하나의 HTML 파일이며, 서버나 설치 없이 열립니다. 투표는 화면 안에서만 계산되고 저장되지 않습니다.
- 각 페이지 끝에 지식 색인과 온톨로지·서지 꾸러미(JSON-LD · Turtle · CSV · CSL-JSON · BibTeX · RIS)가 있습니다.
- `docs/`: 이미지 제작 명세서, 표지 지시문, 페르소나 감사 보고서, 시리즈 등록부 추가분

교육용 해설이며 보안 점검 도구가 아닙니다. 토론자의 편은 캐릭터 역할로, 특정 기업·제품의 입장을 대변하지 않습니다.
